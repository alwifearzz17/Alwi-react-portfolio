# ⚡ Alwi — Neon Developer Portfolio

A single-page React portfolio for **Muhammad Alwi bin Muhammad Sem Yap**, a Full Stack & AI
Software Developer. Styled around a terminal / graph-network aesthetic — a nod to the
Neo4j fraud-detection systems and enterprise platforms behind the work it showcases.

## ✨ Features

- **Animated terminal hero** — a typewriter `whoami` intro with a blinking cursor
- **Live graph-network backdrop** — an animated SVG of pulsing nodes and dashed
  connection lines behind the hero section
- **Scroll-spy navigation** — the nav bar highlights the section currently in view
  using an `IntersectionObserver`
- **Circuit-style experience timeline** — a glowing vertical trace connecting each
  role, with nested cards for client engagements (Microlink, Lonpac, ITM)
- **Categorized skill chips** — languages, frameworks, and databases grouped and
  color-coded
- **One-click resume download** — the PDF is embedded directly in the app, so the
  download button works instantly with no server request
- **WhatsApp & email contact** — tap-to-chat via `wa.me`, one-click copy for email
- **Fully responsive** — collapses gracefully down to mobile

## 🛠️ Tech Stack

| Layer      | Choice                          |
|------------|----------------------------------|
| Library    | React 18                        |
| Build tool | Vite                             |
| Styling    | Plain CSS-in-JS (no framework)   |
| Fonts      | JetBrains Mono, Inter            |
| Hosting    | Netlify                          |

No UI framework or CSS library is used — every neon glow, chip, and animation is
hand-written CSS scoped inside the component.
